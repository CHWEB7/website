# Voltron Digital

Personal bio / CV landing site — dark hero with a GitLab-inspired interactive background.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Canvas pointer-reactive mesh background

## Develop

```bash
npm install
npm run dev
```

## Brand

- Base: `#1a1826`
- Accent gradient: `#AB3BFF` → `#FD80FF` (from the geometric logo)
